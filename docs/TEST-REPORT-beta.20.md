# 2.0.0-beta.20 测试与发布记录

## 目的

2026-11-23 复查一个月里 47 条“Google 搜索（广告/自然未确定）”询盘：没有一条是点广告直接进来的；4 条是先点过广告（访客当时没同意 Cookie）、后来又从谷歌自然搜索回来提交的。用户决定：

1. 从谷歌来、没有广告标记的，标“Google 自然搜索”；`gad_source` 也算广告标记。
2. 先点广告再回来的：72 小时内来源记为 Google Ads（首次进站是广告），按广告系列统计，并注明“之前点过广告”；超过 72 小时算自然。只对同意了 Cookie 的询盘做。

依据：六个 Google Ads 账户都开了自动标记，近 30 天有点击的 72 个系列都带系列后缀；服务器访问记录看到的广告进站次数是 Ads 点击数的 99%–152%（11/16–21）。

## 变更

- `inquiry-source.php`：Google 来源且无广告标记 → “Google 自然搜索”（Bing 等仍为“搜索（广告/自然未确定）”）；`gad_source`、`gad_campaignid` 视为 Google Ads 标记。
- `request-attribution.php`、`form-context.js`：保留 `gad_source`、`gad_campaignid` 两个参数；“Google 自然搜索”的平台记为 google_organic。
- 新增 `ad-return.php`，在提交校验时调用：只处理“同意 Cookie + Google 自然搜索”的询盘；读设置里的访问记录文件（含当天之前已压缩的文件，只读，最多 3 秒 / 300 MB），找同一 IP 或同一 IPv6 /64 在提交前 72 小时内最近一次广告进站（按本插件的 Google Ads 判断规则）。找到则：
  - 来源 Google Ads（平台 google_ads，另有 attribution.ad_return 标记），系列、广告组、关键词、设备、地区取自那次广告进站；点击编号一律不复制；
  - 询盘详情新增“首次广告进站”：之前点过广告：系列 xx，xx 分钟前（2 小时以上写小时）；
  - 小满备注增加“来源备注：…”，线索标题带系列代码，来源词仍为“站名谷歌”。
- `configuration.php`：设置“广告回访核对”（访问记录文件路径，可用 *；往前小时数，默认 72，1–168）。留空即关闭。
- 已有询盘不改。版本 `2.0.0-beta.20`。
